BamBam Admin

Sign in with a GitHub access key to edit the website. Changes go live about a minute after you publish.

How to get an access key (2 minutes, one time)
  1. Open GitHub → New fine-grained token.
  2. Name it Bam Bam Admin and pick an expiration (1 year is fine).
  3. Under Repository access, choose Only select repositories → bam-bam-reviews-play.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

The key is only saved in this browser. It can only touch this one repository, and you can delete it on GitHub any time.

Inbox setup (free, uses a Google Sheet)
  1. Create a new Google Sheet named Bam Bam Pitches.
  2. In the sheet, open Extensions → Apps Script. Delete what's there and paste the code below.
  3. Change CHANGE-ME on the first line to a secret password of your own.
  4. Click Deploy → New deployment, choose type Web app, set Execute as: Me and Who has access: Anyone, then Deploy and allow access.
  5. Copy the Web app URL and paste it below with your secret, then Publish changes.
